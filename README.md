# 신재우 | 서비스 기획 포트폴리오

서비스를 기획하고 직접 구현해 온 프로젝트를 모았습니다. 각 프로젝트에서 어떤 문제를 다뤘고, 무엇을 맡았으며, 어떤 근거로 기능을 설계하거나 수정했는지 정리했습니다.

**[포트폴리오 보기](https://13jvv-portfolio.vercel.app/)**

## 대표 프로젝트

### [CrowdSense](https://13jvv-portfolio.vercel.app/projects/crowdsense/)

인파 경보 이후 담당자가 조치·전파·보고를 준비할 수 있도록 만든 AI 관제 지원 서비스입니다.

- **담당:** 기획, 설계, 개발, 배포 전 과정
- **주요 작업:** 공공데이터의 관측 지연과 오차를 판정에 반영하고, AI 대응 문안에 판단 근거와 확인이 필요한 항목을 함께 표시했습니다.
- **결과:** 제4회 재난안전데이터 활용 창업경진대회 최우수상(행정안전부 장관상)을 수상했습니다. 실제 위험 예측 성능과 현장 대응 효과는 별도 검증이 필요합니다.

### [It's me · 잇츠미](https://13jvv-portfolio.vercel.app/projects/itsme/)

디지털 명함을 만들고 교환한 뒤, 만남 기록과 변경된 연락처를 확인하는 앱입니다.

- **담당:** 기획, 디자인, 개발, 배포를 혼자 맡았습니다.
- **주요 작업:** 명함 생성·QR 공유·연락처 관리·AI 만남 브리핑을 구현했습니다. 사용자 피드백을 바탕으로 세로 명함과 내 명함·지갑·스캔·설정의 네 개 탭으로 화면을 다시 구성했습니다.
- **결과:** App Store와 Google Play에 출시했습니다. 상세 기록에서 화면 개편 과정과 심사 대응, 실기기에서 발견한 문제를 다룹니다.

### [반갑꼬리](https://13jvv-portfolio.vercel.app/projects/pet/)

반려동물의 몸무게와 품종에 맞춰 여행 시설의 동반 조건을 확인하는 앱입니다.

- **담당:** 3인 팀에서 앱 프론트엔드, 기능·DB 설계, API 연동, 배포를 맡았습니다. 백엔드 구현은 팀원 2명이 담당했습니다.
- **주요 작업:** 시설의 동반 조건과 반려동물 정보를 대조해 근거를 보여주는 흐름을 설계하고 연결했습니다. 조건이 없거나 모호한 시설은 확인이 필요하다는 점을 표시했습니다.
- **결과:** App Store에 출시했습니다. 실제 시설 데이터와 실기기로 판별부터 출입증까지 이어지는 흐름을 점검하고 조회 오류를 수정했습니다.

### [생성형 AI 서비스 구독 모델 분석](https://13jvv-portfolio.vercel.app/projects/subscription/)

가격과 기능의 어떤 조합이 AI 서비스 구독 선택에 영향을 주는지 살펴본 4인 팀 연구입니다.

- **방법:** 113명의 설문 응답을 바탕으로 이산선택실험(DCE)과 조건부 로짓 분석을 진행했습니다.
- **주요 내용:** 가격·정확도·보안성·개인화·전문성의 선호를 비교하고, 가상 서비스 구성에 따른 선택 확률을 추정했습니다.
- **결과:** 실험에서 설정한 속성 범위에서는 전문성의 상대적 중요도가 가장 높았습니다. 표본과 모형의 한계를 함께 정리했으며, 실제 구매 행동이나 시장점유율을 측정한 결과는 아닙니다.

## 그 밖의 프로젝트

[ETC 프로젝트 모음](https://13jvv-portfolio.vercel.app/projects/etc/)에서 세 가지 사례를 더 볼 수 있습니다.

- **캠퍼스 안전 자원 배분:** 순찰 인력과 정비 자원의 배분 방식을 설계하고, 강화학습 적용과 비교 검증 계획을 정리했습니다. 개념 설계 단계의 프로젝트입니다.
- **생산공정 병목 개선:** Arena로 생산라인을 모델링하고, 병목 공정과 개선안을 시뮬레이션으로 비교했습니다.
- **PPO 착륙 정책 실험:** LunarLander에서 설정과 시드를 바꾼 30회 학습을 비교해 평균 보상과 결과의 변동을 살펴봤습니다.

## 이 저장소에 대해

이 저장소에는 포트폴리오 웹사이트의 소스와 프로젝트별 상세 기록이 있습니다. 사이트는 HTML, CSS, JavaScript로 구성되어 있습니다.

홈의 애니메이션은 프로젝트를 설명하기 위해 재구성한 화면입니다. 프로젝트의 구현 과정과 결과, 관련 링크는 각 상세 기록에 정리했습니다.
