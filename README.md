# JAEWOO — Field of possibilities

순수 블랙 공간에서 일곱 개의 프로젝트를 탐색하는 정적 포트폴리오입니다.

## 미리보기
이 폴더에서 `python3 -m http.server 4173`을 실행한 뒤 http://localhost:4173 에 접속합니다. 빌드나 백엔드가 필요하지 않습니다.

## 인터랙션
- 중앙에서 일곱 프로젝트로 분기되는 원근 공간
- 마우스 위치에 따라 움직이는 공간과 연결선을 따라 이동하는 빛
- 바닥 패널에 호버하거나 키보드로 포커스하면 떠오르는 영상 화면
- 프로젝트를 선택하면 전체 화면 상세 보기, 이전·다음 프로젝트 이동
- 모바일에서는 첫 터치로 영상 미리보기, 두 번째 터치로 상세 보기
- 별도 프로젝트 목록과 소개 창, Escape로 상세 창 닫기
- Motion 버튼과 운영체제의 동작 줄이기 설정 지원

## 파일
- `index.html`: 공간·목록·상세·소개 구조
- `style.css`: 타이포그래피, CSS 원근 공간, 홀로그램 전환
- `app.js`: 공간 배치와 입력·상태·상세 화면 제어
- `scenes.js`: 프로젝트 데이터와 Canvas 모션 장면
- `projects/*/index.html`: 기존 상세 페이지 사본

프로젝트 정보는 `scenes.js`의 `projects` 배열에서 수정합니다. 화면 연출은 실제 서비스 녹화가 아니라 프로젝트를 바탕으로 재구성한 Canvas 데모입니다. 관제 데이터·탐색 장소·차트 막대 길이는 예시이며, 루나랜더는 학습 에이전트 녹화가 아닌 착륙 연출입니다. CSS 3D와 Canvas로 구현했으며 WebGL 모델을 사용하지 않습니다.

Vercel 배포 시 이 폴더를 Root Directory로 지정하고 Framework Preset은 Other, 빌드 명령은 비워둡니다. 외부 배포는 아직 하지 않았습니다.
