문제 정의왜 이 문제이고, 왜 강화학습인가

착륙 과제에서는 위치·속도·기울기에 맞춰 엔진을 조절해야 합니다. 이 프로젝트의 질문은 PPO가 이 과제를 학습하는지, 그리고 같은 학습 예산에서 어떤 설정이 더 높은 보상과 작은 시드 간 변동을 보이는지였습니다.

상태·행동·보상이 정의된 LunarLander를 사용해 설정을 통제하며 반복 학습했습니다. 2차원 시뮬레이션에서의 정책 학습과 실험 비교가 범위이며, 실제 로켓 제어나 기존 제어기 대비 우월성을 검증한 연구는 아닙니다.

접근PPO 선택과 실험 설계

왜 PPO였는가

정책 갱신 폭을 제한하는 클리핑과 Actor-Critic 구조를 갖춘 PPO를 사용했습니다. Stable-Baselines3의 같은 구현에서 세 설정을 바꾸며 비교할 수 있어 실험 조건을 통일했습니다. DQN·TRPO와의 직접 성능 비교는 수행하지 않았습니다.

실험을 이렇게 설계했습니다

먼저 Stable-Baselines3 기본값으로 베이스라인을 학습시켜 성능의 한계가 아니라 불안정성이 문제라는 걸 확인했습니다. 같은 설정인데도 시드에 따라 결과가 갈렸기 때문에, 원인이 될 만한 세 요소를 하나씩 분리해 비교했습니다.

채택은 256×256이 아니라 128×128이었습니다

256×256의 학습 평균이 242.45점으로 더 높지만, 최종 구성에는 128×128을 채택했습니다. 작은 모델로도 학습 평균이 200점을 넘는다는 점과 모델 크기를 함께 고려한 선택입니다. 다만 학습 시간·메모리 실측이 없어 연산 효율이 더 좋다고 정량적으로 입증한 것은 아닙니다.

학습률 그래프의 범위 값은 발표자료 보고값입니다. 이 페이지에 시드별 원표가 없어 최대−최소 계산은 원본 로그 확인이 필요합니다.

약 50만 스텝 종료 시점의 평균은 낮은 학습률에서 작았고, 0.0005 이상에서는 200점을 넘었습니다. 이 결과는 정해진 학습 예산 안의 비교이며 최적해 도달 여부를 증명하지 않습니다.

최고 평균은 0.001, 채택값은 0.0015였습니다

평균은 265.7 대 265.3이고 보고된 시드 간 범위는 3.4 대 14.6입니다. 최종 구성에서는 수렴 속도를 고려해 0.0015를 선택했지만, 이 표에는 200점 도달 스텝 수가 없습니다. 최고 평균 설정으로 표시하지 않고, 수렴 속도와 안정성의 선택 근거는 원본 학습 곡선에서 추가 확인해야 합니다.

최종 구성선택한 조합과 검증
# 최종 모델
model = PPO(
    "MlpPolicy", env, verbose=1, seed=SEED,

    learning_rate=0.0015,          # 수렴 속도 기준 선정
    policy_kwargs=dict(net_arch=[128, 128]),   # 성능당 연산 비용
    ent_coef=0.01,                 # 탐험·이용 균형
    gamma=0.99,

    tensorboard_log=log_path,
)

발표자료는 최종 조합의 학습 평균이 200점 기준선을 넘었다고 보고했습니다. 별도 평가 에피소드의 원점수와 성공률은 이 페이지에 없으므로, 평가 절차에 따른 Solved 판정까지 확정하지 않습니다. 상단 착륙 그림은 과제 설명용 재구성이며 학습 성능의 증거로 사용하지 않습니다.

이 실험에서 얻은 결론

같은 약 50만 스텝 예산에서 구조·학습률·엔트로피 설정에 따라 학습 보상이 달라졌습니다. 최고 평균만으로 설정을 고르지 않고 시드 간 범위와 모델 크기를 함께 검토했습니다. 더 긴 학습과의 비교나 설정 간 상호작용은 이번 실험에 포함되지 않았습니다.

한계알고 있는 것과 다음 단계

세 시드의 학습 로그 비교에서 관측한 경향입니다. 설정 선택을 더 강하게 뒷받침하려면 다음 검증이 필요합니다.

시드 3개는 통계적 결론을 내기에 적은 표본입니다

시드 간 편차가 최대 110점에 달하는 환경에서 n=3의 평균 차이는 우연일 수 있습니다. 학습 시드를 추가해 학습 간 변동을 확인하고, 각 학습 정책을 별도 평가 에피소드에서 재측정해야 합니다. 평가 반복은 학습 시드 반복을 대체하지 않습니다.

한 번에 하나씩 바꾼 실험이라 상호작용을 못 봅니다

학습률과 엔트로피 계수는 서로 영향을 주지만, 각 스윕은 나머지를 기본값에 고정한 상태에서 진행했습니다. 다음에는 두 축을 격자로 함께 훑는 것이 정확합니다.

학습 곡선의 보상은 평가 성능이 아닙니다

비교에 쓴 값은 학습 중 롤아웃 보상이라 탐험 노이즈가 섞여 있습니다. 학습에 쓰지 않은 평가 시드와 고정된 정책 설정으로 여러 에피소드를 실행해 평균·분산·성공률을 따로 보고해야 합니다.

후속 검증에서는 환경 버전과 전체 설정을 고정해 재현하고, 바람 등 변경 조건에서의 일반화 성능을 별도로 비교할 수 있습니다.
