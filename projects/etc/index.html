01 SYSTEM DESIGN · CONCEPT

캠퍼스 안전 자원 배분

Safety, by design.

상세 기록 더 읽기 ↗
문제
캠퍼스 생활권의 위험을 감지한 뒤 순찰 인력과 정비 자원을 어디에 먼저 배치할지 다뤘습니다.
선택
즉시 순찰과 장기 정비를 분리하고, PPO의 상태·행동·보상과 수집–분석–실행 흐름을 설계했습니다.
결과·범위
관제 대시보드와 SUMO 비교 검증 계획을 제안서로 정리했습니다. 개념 설계 단계이며 실제 배치·학습 성능·안전 개선 효과는 검증하지 않았습니다.

02 PROCESS SIMULATION

생산공정 병목 개선

Less waiting, better flow.

상세 기록 더 읽기 ↗
문제
칫솔 생산라인을 Arena로 모델링해, 공정의 합류와 묶음 처리에서 발생하는 대기 병목을 찾았습니다.
선택
검수 통합·U자형 셀 배치·배치 출고 제거를 함께 적용하고 동일한 실행 조건으로 비교했습니다.
결과·범위
시간당 생산량 182→338개(+85.7%)는 모형 내 결과입니다. 실제 공장 효과는 미검증이며, 시간 지표는 원자료의 min 표기와 모델의 Seconds 설정이 달라 단위 확인이 필요합니다.

03 REINFORCEMENT LEARNING

PPO 착륙 정책 실험

Learning to land.

상세 기록 더 읽기 ↗
문제
LunarLander에서 같은 PPO 설정도 시드에 따라 학습 보상이 달라지는 문제를 살펴봤습니다.
선택
신경망 구조·학습률·엔트로피 계수의 10개 설정을 3개 시드에서 비교하는 총 30회 학습으로 평균과 시드 간 변동을 함께 검토했습니다.
결과·범위
학습 로그를 바탕으로 최종 파라미터를 선택했습니다. 2차원 시뮬레이션의 학습 비교이며, 별도 평가 에피소드의 성공률이나 실제 제어 효과는 검증하지 않았습니다.
