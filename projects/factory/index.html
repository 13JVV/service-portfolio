원인에 대응한 세 가지 개선안

각각 AS-IS 문제, TO-BE 설계, 기대효과 순으로 정리했습니다.

검수

검수 작업존 통합

기존

  • 매 단계 검사로 공정 흐름이 반복적으로 끊김
  • 검사 대기열이 쌓이며 전체 리드타임 지연

개선

  • 직렬로 붙어 있던 중간 검수 모듈을 삭제
  • 통합 검수존을 신설해 병렬로 일괄 검수
  • 중간 정체 구간 제거로 Non-Stop Flow 구성

설계 의도: 검사 대기 분산과 공정 흐름 연속화. 품질 유지 여부는 별도 검증 필요

배치

직선형 라인 → U자형 셀

기존

  • 긴 일자형 라인으로 작업자 간 소통·협업 차질
  • 끝에서 처음으로 돌아오는 편도 공차 발생

개선

  • 입구와 출구를 한곳으로 모아 순환형 동선 구성
  • 한 작업자가 투입과 배출을 동시에 관리
  • 포장 작업자를 set으로 묶어 병목 구간을 돕는 다능공 운영

설계 의도: 이동 동선 축소와 병목 구간의 작업자 지원. 단독 적용 효과는 미측정

출고

배치 출고 → 1개 흐름

기존

  • 출고 단위(50개)를 채우려 완제품이 창고에 체류
  • 배치 완료 대기로 출고 지연과 재고 비용 상승

개선

  • Batch 모듈 삭제, 완성 즉시 1개 단위 출고
  • 완제품이 공장에 머무는 시간 최소화

설계 의도: 출고 수량을 채우는 대기 제거. 재공품·물류 비용 효과는 미측정

검증 범위와 남은 질문

개선안의 방향은 시뮬레이션으로 비교했고, 현장 적용 판단에 필요한 검증은 남아 있습니다.

  1. 시간 단위와 지표 정의요약표의 min 표기와 모델의 Seconds 설정이 일치하는지 원본 리포트에서 확인해야 합니다. 리드타임·대기·이동 시간의 집계 대상도 함께 확인해야 절대값을 해석할 수 있습니다.
  2. 반복 실험의 불확실성5회 반복 중 결합 대기열은 평균 426.83에 Half Width 371.82로 변동이 큽니다. 추가 반복과 신뢰구간 확인이 필요하며, Warm-up 0 설정은 종료형 8시간 운영을 비교하려는 목적에 적합한지도 검토해야 합니다.
  3. 개선안별 기여도세 개선안을 동시에 적용했으므로 생산량 증가를 어느 한 변경의 효과로 돌릴 수 없습니다. 개별 적용과 조합 실험으로 상호작용을 확인하는 것이 다음 단계입니다.
  4. 품질과 실행 비용불량 검출률·재검사 비용·작업자 다기능화 비용은 비교하지 않았습니다. 검수 통합의 품질 영향과 한 개씩 출고하는 운영의 물류 제약을 확인해야 합니다.
